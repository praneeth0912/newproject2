

Project Name: Scientific Calculator & Text Utility Web Application
Version: 1.0
Project Type: Python Flask Web Application
Development Methodology: Incremental Development using Git & GitHub

1. Introduction
The purpose of this project is to develop a web-based application using Python and Flask that provides users with mathematical calculation capabilities and text analysis utilities through a modern, user-friendly interface.

The project will be developed in two phases:
- Website 1: Scientific Calculator
- Website 2: Scientific Calculator with Text Utility

2. Project Objectives
- Develop a responsive web-based scientific calculator.
- Implement basic arithmetic operations.
- Implement scientific mathematical functions.
- Develop a text utility module.
- Follow a modular software architecture.
- Maintain the project using Git and GitHub.
- Learn Flask framework and web application development.

3. Scope

Website 1 – Scientific Calculator
Basic Operations:
- Addition
- Subtraction
- Multiplication
- Division

Website 2 – Scientific Calculator + Text Utility
Includes all calculator features plus:
- Count Letters
- Count Words
- Count Vowels
- Reverse Text
